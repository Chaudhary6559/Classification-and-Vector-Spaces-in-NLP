# 🧪 Assignments

## 1. Logistic Regression for Tweet Sentiment Analysis

**Focus:** Sentiment Analysis · Text Classification · Logistic Regression

The first assignment implements **logistic regression from scratch** for binary sentiment classification of tweets.

The project covers:

* Text feature extraction
* Sigmoid function
* Cost function
* Gradient descent
* Logistic regression training
* Tweet sentiment prediction
* Test-set evaluation
* Error analysis

### Main Concepts

`Logistic Regression` · `Binary Classification` · `Sentiment Analysis` · `NLP` · `Feature Extraction` · `Sigmoid Function` · `Gradient Descent`

---

## 2. Naive Bayes for Tweet Sentiment Analysis

**Focus:** Probabilistic Classification · NLP · Sentiment Analysis

The second assignment applies **Naive Bayes** to classify tweets as positive or negative.

The project explores word counts, conditional probabilities, sentiment ratios, prediction, and error analysis.

### Main Concepts

`Naive Bayes` · `Bayes Theorem` · `Conditional Probability` · `Word Frequencies` · `Sentiment Analysis` · `Text Classification` · `Error Analysis`

---

## 3. Hello Vectors: Exploring Word Embeddings

**Focus:** Word Embeddings · Vector Space Models · Semantic Similarity

The third assignment introduces **word vectors**, representing words as numerical vectors that capture semantic relationships.

The project explores:

* Word embeddings
* Word analogies
* Country-capital relationships
* Cosine similarity
* Euclidean distance
* Prediction accuracy
* Principal Component Analysis (PCA)
* Two-dimensional embedding visualization

### Main Concepts

`Word Embeddings` · `Word Vectors` · `Vector Space Models` · `Cosine Similarity` · `Euclidean Distance` · `PCA` · `Dimensionality Reduction`

---

## 4. Naive Machine Translation and LSH

**Focus:** Machine Translation · Cross-Lingual Embeddings · Similarity Search

The fourth assignment combines **cross-lingual word embeddings** with **Locality Sensitive Hashing (LSH)**.

The first part develops a simple machine translation system by learning a linear transformation between English and French embedding spaces.

The second part applies LSH to document embeddings for efficient approximate nearest-neighbor search.

### Main Concepts

`Word Embeddings` · `Cross-Lingual Embeddings` · `Linear Transformation` · `Machine Translation` · `Nearest-Neighbor Search` · `Document Embeddings` · `LSH` · `Approximate Search`

# 📈 Learning Progression

The four assignments provide a progression from basic supervised text classification to vector-based NLP applications:

### Assignment 1 — Classification

Learn how **Logistic Regression** can be implemented from scratch and applied to sentiment analysis.

### Assignment 2 — Probabilistic NLP

Apply **Naive Bayes** to sentiment classification and investigate how word probabilities contribute to predictions.

### Assignment 3 — Vector Space Models

Move from individual text features to **word embeddings**, where words are represented as vectors with meaningful geometric relationships.

### Assignment 4 — Advanced Vector Applications

Apply vector representations to **machine translation** and use **LSH** for efficient similarity search.
